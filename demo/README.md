## Golden Demo

The recommended walkthrough uses the Shantabai Pawar synthetic pension case and demonstrates:

1. Citizen intake through **SAMVAAD**
2. Payment-chain investigation through **KHOJ**
3. Evidence-based diagnosis through **NIDAAN**
4. Dependency-aware **YOJNA** planning
5. Action document generation through **KARM**
6. Deterministic policy/guardrails through **NYAYA**
7. Evidence verification through **SATYAPAN**
8. Follow-up and watchdog through **ANUSARAN**
9. New passbook evidence triggering **PLAN v2** re-planning

All demo beneficiary data is synthetic.
